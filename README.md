# Under the City

Free places to study, get help, and find things to do after school in New York.

Live at [under-the-city.vercel.app](https://under-the-city.vercel.app).

Every listing links to where we found it. If a source didn't say something, the app says "Unknown" instead of guessing. No accounts, nothing leaves your phone.

It's plain HTML, CSS and JavaScript. To run it locally:

```
python3 -m http.server
```

Listings are in `data/listings.json`. If something's wrong, open an issue.

Made by Zemu Liu and Eric Zhuo for the Congressional App Challenge.
